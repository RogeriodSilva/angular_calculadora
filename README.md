# Calculadora Prática

Um projeto simples de calculadora desenvolvido com [Angular](https://angular.io/).

## 🚀 Funcionalidades

* Operações matemáticas básicas (adição, subtração, multiplicação, divisão).
* Interface limpa e minimalista.

## 🛠️ Tecnologias Utilizadas

* Angular
* HTML / CSS / TypeScript

## 📦 Como executar o projeto

1. Certifique-se de ter o [Node.js](https://nodejs.org/) e o [Angular CLI](https://angular.io/cli) instalados.
2. Clone o repositório.
3. Navegue até a pasta do projeto e instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   ng serve
   ```
5. Abra o navegador e acesse `http://localhost:4200/`.
